# Book Source Craft 文档说明

这组文档是写给“准备适配书源插件的人”看的。

目标很简单：

**帮你尽快弄清楚一个 LegadoHub 插件最少要怎么组织、怎么写、怎么验证。**

这里不是专题研究资料库，而是一套更偏实操的帮助文档。

## 推荐阅读顺序

### 1. 先看模板

- [书源插件模板（中文）](/C:/Home/Workspace/UGit/legado-hub/docs/skills/book-source-craft/references/source-plugin-template.zh-CN.md)

适合场景：

- 你第一次写 LegadoHub 插件
- 你想先知道插件目录最少长什么样
- 你想快速拿到一个能改的骨架

### 2. 再看流程

- `references/plugin-source-workflow.md`

适合场景：

- 你已经知道基础骨架
- 现在想知道适配一个真实站点时应该按什么顺序推进

### 3. 最后看扩展参考

- `references/aggregate-source-pattern.md`
- `references/public-source-references.md`
- `references/stage-2-plugin-production.md`

适合场景：

- 你要做聚合源
- 你要参考公开书源模式
- 你要把插件做得更稳定、更可验证

## 这里保留什么

这里保留的是：

- 插件模板
- 插件适配方法
- 插件目录约定
- 插件验证思路

这里不应该保留的是：

- 某个具体站点的逆向过程
- 一次性的抓包记录
- 临时分析结论
- 与运行无关的大量背景资料

简单说：

**这是一套“怎么写插件”的帮助文档，不是“怎么研究某个站”的档案馆。**

## 如果你只想看一份

那就先看：

- `references/source-plugin-template.zh-CN.md`

它是这组文档里最适合直接上手的一份。
