## 6. 第一批水印与异常候选

### 6.1 shuhaige_net

150/150 章、3 本书出现同一模板：

```text
喜欢{书名}请大家收藏：(m.shuhaige.net){书名}书海阁小说网更新速度全网最快。
```

另有跨书出现的“无错章节将持续更新、站内无广告、请收藏推荐”模板。两类均带明确站点标识，位于固定边界，属于高置信插件专属水印候选。

### 6.2 sto_com

3 本书中发现 13 个聚类家族，典型变体：

```text
sto9.co🎊m提醒您查看最新内容
想获取本书最新更新，请访问sto9.co⛅m
阅读更多内容，尽在s🎶to9.com
本章节来源于st🎆o9.com
```

域名中的表情位置变化，完整字符串不会稳定重复。后续规则应基于稳定 token 顺序和有限长度变量区间，不能枚举具体表情，也不能使用无限 `.*`。

### 6.3 shumilou_top

跨书发现：

```text
[www.69kanbao.com]
ｈｔｔｐｓ：
```

前者是明确外站残留候选；后者证据不足，必须与相邻行合并审查，不能单独删除所有 `https:` 文本。

### 6.4 hjwzw_com

跨书出现：

```text
由中华百科研究会（China Encyclopedia Research Society）维护运行
本文来源：www.小shuo8.cc
古籍群：81875285
```

这批内容更像正文容器混入外站页面或错误转载内容。应先核对原始 HTML 和正文选择器；在证明只是独立水印前，不写宽泛净化规则。

### 6.5 误报边界

聚类也发现“第二天早上。”等普通正文重复句，以及分页提示。普通重复句不能作为水印。

`0xs_net` 的 150 章旧样本中，110 章残留“本章未完，点击下一页”。实网追踪确认插件已经合并后续正文，只是页间提示未清理；`0.2.1` 改为在分页自然结束或进入下一章后精确删除提示，循环或超过上限时仍保留。已知多页章实测从 3722 字符变为 3634 字符，仅删除 4 个提示，正文链路不变。旧 JSONL 保留为修复前证据，不回写历史原文。

### 6.6 lingdiankanshu_com

3 本书中发现两个跨书异常模板：

```text
正在手打中，请稍等片刻，内容更新后，请重新刷新页面，即可获取最新更新！
零点看书全文字更新,牢记网址:www.23txti.com
```

第二条是明确站点水印候选。第一条是未完成正文占位页，应在插件章节读取阶段判定为空或失败，不能净化后当作完整正文使用。

### 6.7 已固化规则

2026-07-31 按用户继续执行授权，对候选原文、位置和反例逐项复核后，将以下规则固化为插件专属净化：

| 插件 | 已批准范围 | 明确不纳入 |
|---|---|---|
| `shuhaige_net` | `m.shuhaige.net` 收藏尾注、书海阁无错更新尾注 | 三类分页提示、普通句“第二天早上” |
| `sto_com` | `sto9.com` 的 ASCII、数学字形及有限插入字符变体 | 不使用单独的“最新内容”“请访问”等宽泛话术 |
| `lingdiankanshu_com` | “零点看书全文字更新，牢记网址”尾注 | “正在手打中”按空正文占位处理，不作为水印规则 |
| `shumilou_top` | `[www.69kanbao.com]` 外站残留 | 单独 `https:` |
| `hjwzw_com` | 中文百科页脚、`小shuo8.cc` 来源和版权尾注、古籍群及菜单残留 | 正常古典小说正文 |
| `czbooks_net` | 52 书库收藏推荐尾注 | 单书出现的新小说网尾注 |
| `dxtxt_cc` | 句内“看最新章节 / 完整章节”动态分隔符注入、独立全角 `dxtxt` 标识 | 作者有话要说；宿主句子的前后正文 |
| `twkan_com` | `GOOGLE搜索TWKAN`、`台湾小说网→花体域名` | 普通 Google 搜索描述、不带箭头的站名或单独 `TWKAN` |

声明式正则只作用于对应插件，变量区间有明确上限；`dxtxt_cc` 仅在正文解析阶段删除满足完整结构证据的句内片段。没有新增全局规则，也没有使用无限 `.*`。
