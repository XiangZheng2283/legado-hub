## 2. 本轮完成内容

### 2.1 阅读与章节语义

- Legado 目录输出补齐 `isVip`、`isPay` 和 `previewOnly` 的一致语义。
- `isVip=true` 只表示 VIP 章节；`isPay=true` 只表示该 VIP 章全文可读。
- VIP 预览固定为 `previewOnly=true`、`isVip=true`、`isPay=false`，避免阅读端把预览误判为已购全文。
- 书库和详情页进度改为“全文覆盖率”，预览章节不推进已完成数。
- 连载书即使当前目录全文覆盖率达到 100%，也显示“已同步 · 追更中”，用脉冲状态表达等待更新，不把进度满格解释为作品完结。
- 详情页统计总章数取数据库与文件投影的较大值，避免迁移或同步窗口内分母过小导致虚假满进度。

### 2.2 订阅、恢复与输入边界

- 订阅搜索 `page` 参数严格限制在 `1..1000`，越界请求在 API 边界拒绝。
- 启动恢复任务按书去重，避免同一本共享书因重复候选被并发恢复。
- Cookie 迁移、孤儿任务清理、词库更新等启动任务失败时记录 warning，不再静默吞掉异常。
- 保存 Cookie 后的插件探测改为单插件隔离；某个插件失败不会阻止其他官方插件刷新状态。
- 损坏 JSON 输入记录脱敏 warning，同时保持调用边界可恢复。

### 2.3 全系统日志与会话安全

- SSE 日志 tail 保留尚未写完的 JSON 尾行，下一次读取时继续解析。
- 文件读取失败时不推进偏移，避免临时 I/O 错误永久跳过日志。
- UTF-8 中文日志统一使用字符偏移，避免字节偏移和文本 seek 混用造成截断。
- 修复订阅建立后日志文件才创建时漏掉首批事件的竞态。
- 登录 Cookie 在直连 HTTPS 或 `X-Forwarded-Proto: https` 时自动附带 `Secure`。

### 2.4 书源统一界面

- 第三方源与官方源共用 `SourceListTable`；官方源只在公共列基础上追加登录、刷新等认证字段。
- 移除第三方源低价值的详情、单项检测入口；保留运行期真正使用的 Ping 状态。
- 批量选择复选框并入表格标题行。
- 两类书源使用融入列表卡片顶栏的横向 Tab；官方源与第三方源均接入表头批量选择。
- 解析能力统一使用中文短标签，Ping 列只保留单行延迟、不可达或未检测占位符。
- 官方源隐藏插件 ID、格式/分类、认证模式和激活列，将账号与检查信息收进登录状态列；禁用插件使用整行灰度，Browser 模式在名称旁显示标签。
- 切换内容使用轻量淡入和位移动画，并尊重 `prefers-reduced-motion`。
- 插件列表加载失败提供明确错误和重试入口。

## 3. 门禁中发现并修复的问题

第一次完整 `verify.ps1` 运行得到 `312 passed / 5 skipped / 1 failed`。失败用例暴露了日志 tail 的真实竞态：SSE 订阅先建立、日志文件随后创建时，初始化逻辑会把新文件末尾当作初始偏移，首批事件因此被跳过。

修复后先运行日志相关定向回归，结果为 `24 passed`；随后重新执行完整门禁并通过。该问题不是通过放宽断言解决，而是调整文件首次出现时的偏移初始化语义。

## 7. 明确延期的产品边界

以下问题需要单独设计或部署约束，不能在夜间迭代中顺手扩大权限面：

- 首次启动 bootstrap 管理员抢占：需要部署侧初始化密钥或一次性本地授权方案。
- 匿名 Reading 数据面：当前发布书可由匿名 Legado 客户端读取；是否绑定订阅者身份需要先固定阅读端认证契约。
- 多 worker 限流与调度：当前进程内状态不保证多 worker 一致性，扩展前需要共享锁和分布式限流边界。
- 删除与归档语义：需要区分用户取消订阅、共享书归档、管理员删除和文件清理，禁止用单一删除动作混合表达。
- hidden 共享书按 ID 订阅：需要先明确“知道 ID 是否等于获得访问权”，再决定 API 是否开放。
