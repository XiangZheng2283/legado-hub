## 本轮修复

- `LogStream` 不再调用会滚动祖先容器的 `scrollIntoView`；新增日志时只更新日志容器自身的 `scrollTop`。
- 用户手动向上查看历史日志后停止自动追尾，回到底部后恢复；URL 变化和组件卸载会关闭旧 `EventSource`。
- `LogStream` 与管理员订阅事件日志统一为浅色控制台样式，移除旧深色终端视觉。
- 书源管理、官方源、用户管理、书籍详情的统计块、页头、表格密度和移动布局统一到当前浅色设计系统。
- 宽表保留稳定最小列宽；管理员候选源卡片补 `min-w-0` 边界，避免表格把 grid 卡片撑出移动视口。
- visual-diff 在移动视口真实验证候选源、章节和官方源表格可以横向滚动，并在日志推送完成后断言页面 `<main>` 未被自动滚到底部。
- 仪表盘状态改由真实启用书源 Ping 统计驱动，展示 `healthy/degraded/pending/idle`、进程运行时长、应用版本和未检测数量，并支持 30 秒轮询与手动刷新。
- 优先级配置由原始多行文本框改为有序列表编辑器，支持新增、删除、上移和下移，继续使用既有数组保存契约。
- 书库列表、书籍摘要和章节列表在页面可见时每 5 秒刷新；管理员实时日志事件按 1 秒窗口合并刷新，后台标签页不触发事件查询。
- schema 12 修复共享书创建者归属：新建时写入 `added_by_user_id`，历史空值仅按明确的 `create` 操作日志回填；普通用户与公开搜索继续隐藏创建者身份。
- 书源管理移除低价值搜索与分类筛选区；第三方源和官方源共用 `SourceListTable`，官方只追加认证字段。Tab 改为悬浮在列表框左侧的竖向图标胶囊，第三方全选框进入表头并移除“详情与检测”按钮。
- 优先级设置从真实插件列表添加书源，显示名称、插件 ID 和官方/第三方类型；已保存但未安装的旧 ID 仍可排序或删除，后端继续使用既有 `string[]` 契约。

## 使用方式

日常回归：

```powershell
cd C:\Home\Workspace\UGit\legado-hub\frontend
node .\visual-diff\run-visual-diff.mjs
```

仅在已审核的有意 UI 变更后更新基线：

```powershell
node .\visual-diff\run-visual-diff.mjs --update-baseline
```

默认 compare 不会自动创建缺失基线；整体或任一场景一致率低于 98% 时命令失败。
`--update-baseline` 只更新已审核基线，报告结果固定为 `NOT EVALUATED`；更新后必须再运行默认 compare 并取得 `PASS`。
