# 前端重设计实施文档

> 状态：历史设计参考。路由边界仍可参考，旧组件方案和实施顺序已废止。
> 当前产品范围以 `docs/PRODUCT.md` 为准；后续执行见 `docs/architecture/console-capability-audit-and-next-plan.zh-CN.md`。

## 1. 设计目标

将 LegadoHub 控制台从"运维后台"转向"阅读订阅工具 + 管理后台"双模式：

- **用户版**：聚焦"找书、订阅、查看可读进度"，信息精简、视觉现代、交互轻量。
- **管理版**：在用户版基础上叠加配置、调试、运维能力，克制不喧宾夺主。
- 两套界面共用同一套视觉语言和基础组件，降低维护成本。

## 2. 产品与结构原则

1. **内容优先**：封面、书名、作者、可读/处理进度、最新章节是最高优先级；内部字段默认隐藏。
2. **一屏一意图**：每个页面只回答一个核心问题。
3. **用户可用性优先**：订阅页和书库页是未来开放给用户的主入口，允许保留更强的品牌语气和更明显的视觉表达。
4. **品牌语气明确采用**：用户入口页面保留轻快、亲近、带一点社区感的语气，不主动压回“纯工具文案”。
5. **日常操作优先，维护操作降级**：普通用户只看订阅和章节；管理员的刷新源映射、重建、删除等操作默认收进管理区域。

```
  订阅管理

```

### 3.2 路由映射

| 用户入口 | 路由 | 管理入口 | 路由 |
|---|---|---|---|
| 订阅 | `/console/subscription` | 订阅管理 | `/console/admin/subscription` |
| 书库 | `/console/library` | 书库管理 | `/console/admin/library` |
| 书籍详情 | `/console/library/:bookId` | 同一详情页内显示管理区 | `/console/library/:bookId` |
| 章节详情 | `/console/library/:bookId/chapters/:chapterId` | 同一章节页内显示管理区 | `/console/library/:bookId/chapters/:chapterId` |

> 只有列表页区分用户入口和管理入口。书籍/章节详情页不新增 `/console/admin/library/:bookId` 路由，避免同一本书出现两个详情地址；通过 `isAdmin` 在同一页面内切换管理区域。

## 5. 用户版：订阅页（`/console/subscription`）

### 5.1 页面目标
让用户快速搜索并订阅想读的书。

### 5.2 布局

- **初始状态**：页面中央只有大标题、副标题和居中的搜索框，简约大气。
- **搜索开始后**：搜索框平滑上移到页面顶部居中，下方出现进度条和瀑布流结果卡片。
- 结果区：使用 `MasonryGrid` 瀑布流卡片网格；具体列数、间距、动画以 UI spec 为准。

### 5.3 订阅卡片结构

卡片采用瀑布流，高度随内容自然撑开，封面统一 3:4 比例。

```
┌─────────────────────────┐
│  [Cover 3:4]            │
├─────────────────────────┤
│  书名              状态  │
│  作者                   │
│  简介（2-3行）          │
│  字数 · 章节数 · 完结   │
└─────────────────────────┘
```

- 封面、标题、简介、底部元数据和 hover 细节以 UI spec 为准。
- 整张卡片可点击：
  - 未入库：打开订阅确认弹窗。
  - 已入库：跳转对应书库书籍详情。

### 5.4 状态展示

| 状态 | 徽章 |
|---|---|
| 可订阅 | `success` |
| 已入库 | `secondary` |
| 搜索中 | `info` |
| 失败 | `destructive` |

### 5.5 搜索进度

- 不展示内部 source_count/success/error/timeout 统计。
- 只显示："搜索中..." + 进度条 + "已找到 N 本"。
- 完成后："找到 N 本相关书籍"。

### 5.6 订阅弹窗

- 普通用户：只显示书名 + "确认订阅" 按钮。
- 管理版：展开显示"开始章节序号"、"完本自动归档"等高级参数。

### 5.7 瀑布流实现

- 使用 `MasonryGrid`，以纯 CSS `columns` 实现。
- 不引入第三方瀑布流库。

## 6. 用户版：书库页（`/console/library`）

### 6.1 页面目标
让用户看到已订阅书籍的可读进度和处理状态。

### 6.2 布局

- 顶部：标题 + 搜索框（左对齐，简洁工具栏）。
- 主体：使用 `MasonryGrid` 瀑布流书籍卡片；具体列数、间距和响应式规则以 UI spec 为准。
- 用户版无表格视图；管理版仍以瀑布流卡片视图优先，不强制提供表格视图。

### 6.3 书库卡片结构

```
┌─────────────────────────┐
│  [Cover 2:3]            │
├─────────────────────────┤
│  书名              完结  │
│  作者                   │
│  进度条                 │
│  可读 23 / 总 100 章    │
│  最新：第 100 章标题     │
└─────────────────────────┘
```

- 封面比例、进度条、hover 和三点菜单细节以 UI spec 为准；卡片高度允许随最新章节、状态提示等内容自然撑开。
- 整张卡片可点击，点击进入书籍详情页。
- 卡片底部状态条：只显示"处理中/已暂停/已完结/异常"之一。
- 用户版无操作按钮；管理版通过卡片右上角三点菜单呼出管理操作。

### 6.4 卡片内部信息优先级

1. 封面
2. 书名 / 作者
3. 进度
4. 最新章节
5. 状态徽章

> 不显示：搜索可见、添加人、章节状态细分、操作按钮。整张卡片可点击。

## 7. 书籍详情页（用户 + 管理共用）

### 7.1 用户视角

- Hero：大封面 + 书名/作者/状态 + 总进度条 + "查看章节"主按钮。
- 快捷信息：总章节、可读章节、免费/VIP 分界、最后更新。
- 章节列表：只显示序号、标题、状态（可读/预览/失败）、VIP/免费类型。
- 不显示：源映射、处理日志、实时日志、字数/源字数列、"处理本章"按钮。

### 7.2 管理视角

在用户版基础上增加：
- Hero 区域右上角"管理"菜单：检查更新、刷新源映射、重新计算状态、重建、删除。
- "检查更新"可作为高频操作露出；刷新源映射、重新计算状态、重建、删除属于维护操作，默认收进管理菜单或折叠维护区。
- 元数据区域（折叠默认收起）：主源、起始章节、策略版本、源映射刷新状态等。
- 源映射摘要（折叠默认收起）：默认只突出异常，如缺官方源、候选源落后、章节数差异过大。
- Tabs 增加"处理记录"、"实时日志"（仅 admin）。
- 章节列表增加：来源、字数/源字数、"处理本章"按钮。

> "修复统计"不作为用户可见按钮。若后端能力仍需保留，前端命名为"重新计算状态"，放在维护区并加确认。

## 8. 管理版：订阅管理页（`/console/admin/subscription`）

### 8.1 与用户版差异

- 复用同样的瀑布流卡片网格。
- 每张卡片额外显示：
  - 候选源摘要徽章（official/third-party、score）
  - 搜索事件日志入口（折叠）
  - 入库参数
- 顶部保留完整搜索统计：官方源完成数、成功/失败/超时。
- 不破坏用户版卡片的可点击行为。

## 9. 管理版：书库管理页（`/console/admin/library`）

### 9.1 与用户版差异

- 复用同样的瀑布流书籍卡片。
- 卡片右上角常驻三点菜单，点击呼出管理操作：暂停/继续、归档、设置、删除。
- 重建不放在书库卡片上，进入书籍详情维护区再执行。
- 不强制提供表格视图；若未来需要批量技术字段查看，再考虑增加表格切换。

> 管理页优先复用 `LibraryPage`，通过 `mode="admin"` 显示额外能力；不要一开始复制出两份相似页面。

## 10. 组件复用策略

### 10.1 新增共享组件

- `BookCard`：用户版书库卡片，接收 `book` + `onClick` + 可选 `actions` slot（用于管理版三点菜单）。
- `SubscriptionCard`：用户版订阅卡片，接收 `card` + `onClick` + 可选 `extra` slot（用于管理版调试信息）。
- `MasonryGrid`：纯 CSS columns 瀑布流容器，作为订阅页和书库页的标准容器。

### 10.2 复用现有 UI 组件

- `Card`, `Button`, `Badge`, `Progress`, `Input`, `Dialog`, `Select`, `Tabs`, `Table`, `DropdownMenu` 继续沿用。

## 11. 实施步骤

1. 调整 `Layout.tsx` 导航结构（已完成）。
2. 更新 `App.tsx` 增加 `/console/admin/subscription`、`/console/admin/library` 路由；书籍/章节详情继续使用现有路由。
3. 创建 `BookCard` / `SubscriptionCard` / `MasonryGrid`。
4. 重写 `LibraryPage.tsx` 为瀑布流书籍卡片，并支持 `mode="admin"` 显示管理入口的额外操作。
5. 调整 `LibraryBookDetailPage.tsx`：用户版精简 + admin 折叠管理区。
6. 重写 `SubscriptionDiscoveryPage.tsx` 为居中搜索 + 瀑布流卡片，并支持 `mode="admin"` 显示调试信息。
7. 运行 lint / typecheck / build 验证。

## 12. 其他页面改造

### 12.1 仪表盘（`/console`）

- 页面目标：一眼看系统健康。
- 现状：5 个统计卡片 + 系统信息卡片，过于朴素。
- 改造：
  - Hero 区：欢迎语 + 当前运行阶段。
  - 4 个 KPI 卡片横向排列：书源总数、已启用、健康、异常。
  - 增加一个"快捷入口"区：订阅新书、进入书库、管理书源。
  - 系统信息合并到右下角小卡片或 tooltip，不占用主区域。

### 12.2 搜索工作台（`/console/search`）

- 页面目标：按书源直接搜索并验证候选结果，本质是管理调试工具。
- 改造方向：
  - 顶部工具栏统一：搜索框 + 书源筛选 + 搜索/取消按钮。
  - 进度区更紧凑：状态徽章 + 进度条 + 简单统计（完成/成功/失败）。
  - 结果表格列精简为：书名、作者、来源、最新章节、评分、操作。
  - 书源进度明细和最近搜索做成可折叠卡片。
  - 详情弹窗优化：左侧封面+元数据，右侧章节/内容，评论面板保留。

### 12.3 书源页（`/console/plugins`）

- 页面目标：管理所有书源插件。
- 改造方向：
  - 顶部工具栏：标题 + 重新加载 + Ping 全部 + 批量操作（选中后显示）。
  - 表格列精简为：名称、能力、类型、状态、Ping、Smoke、最近错误。
  - 隐藏代理、认证模式等列，放到详情页。
  - 每行操作收到"更多"菜单或详情页。
  - 空状态和加载状态使用居中插图风格。

### 12.4 书源详情页（已删除）

- `/console/plugins/:pluginId` 不再保留独立页面。
- 插件元信息、Ping、批量启停和官方登录统一在书源管理页完成，避免重复入口和第二套视觉。

### 12.5 官方源页（`/console/official-sources`）

- 页面目标：管理官方源登录态。
- 改造方向：
  - 顶部标题 + 官方源数量徽章。
  - 表格列精简为：名称、登录模式、账号状态、内容访问、最后检查、操作。
  - 登录状态卡片更美观，使用图标 + 进度条风格。
  - 操作按钮：登录/注销、刷新状态、清除 Cookie（仅未登录且有 Cookie 时显示）。

### 12.6 设置页（`/console/settings`）

- 页面目标：配置系统运行参数。
- 改造方向：
  - 顶部标题 + 保存按钮。
  - 账户安全卡片保留，但布局更紧凑。
  - 书源池、聚合与内容处理、书源优先级、敏感词词库分 Tab 或分 Section 展示。
  - 书源优先级拖拽排序体验优化（可选使用更直观的拖拽，但先用上下箭头实现）。
  - 敏感词词库卡片保留并视觉优化，显示来源/版本/文件数/词条数/更新时间。

## 13. 全局组件/模式补充

### 13.1 页面头部统一模式

```
┌──────────────────────────────────────┐
│ 标题                    [操作按钮组]  │
│ 副标题                                │
└──────────────────────────────────────┘
```

- 标题左对齐，`text-2xl font-bold tracking-tight`。
- 副标题 `text-sm text-muted-foreground`。
- 操作按钮在右侧，移动端换行。

### 13.2 空状态

- 居中图标 + 标题 + 描述 + 可选操作按钮。
- 使用 `text-muted-foreground`，不使用鲜红/鲜绿。

### 13.3 加载状态

- 卡片内使用骨架屏（`Skeleton`）。
- 整页加载使用居中 spinner。

### 13.4 表格规范

- 行 hover 背景色 `hover:bg-muted/50`。
- 操作列居右，最多保留 1-2 个高频按钮，其余收进更多菜单。
- 列标题使用 `text-xs font-medium text-muted-foreground uppercase tracking-wider`。

## 14. 不改动项

- 后端 API 不变。
- 不引入新依赖（继续使用 Tailwind CSS + shadcn/ui）。
- 不新增第二套视觉规范文档；视觉实现统一追随 `legado-hub-ui-spec.md`。
